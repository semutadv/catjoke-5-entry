One cat joke, written for the make.fun bounty "The One-Line Cat Joke
That Lands". The cat knocked the coffee off the desk — not from spite,
but because the warm patch where the coffee stood was the only seat in
the house shaped exactly like a cat's plans for the afternoon.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
